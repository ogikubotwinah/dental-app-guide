給与計算使い方

毎月の給与、昇給、賞与、振込まで。
スタッフ向けの一覧には出していません。

開き方

院内のパソコン、または Tailscale に繋がっている端末から開きます。外部からは開きません。

給与計算を開く

開くとパスコードを聞かれます。これは勤怠アプリの管理パスコードとは別のものです。 勤怠の管理画面に入れる人（勤怠の担当者）は、給与の中身は開けません。

紙に印刷しないでください。給与明細・賃金台帳は画面で確認します（2026-08-21 院長）。 保存が必要なときはPDFにしてください。

画面は4つ

給与月ごとの支給控除一覧。検索・印刷・Excel出力ができます。ここが普段見る画面です。
設定従業員ごとの給与・手当・社会保険・扶養、会社の設定。新しい人の登録もここです。
人件費職種ごと・1人あたり・月ごとの動き、時間外の割合、前月から動いた人。
導入の設定ラマルクとして他院に入れるときの初期設定です。当院では普段使いません。

毎月の流れ（25日払い）

Telegram にこちらから声をかけます。院長がすることは、返信2回だけです。

  1. 18日ごろ「締めのチェック」が届きます。勤怠に直すところがあれば勤怠の担当者へ連絡が行きます。 手入力が要る人（毎月額が変わる方）がいれば、テンプレートが届くので数字を入れて返信します。
    【給与手入力 2026-09】 〇〇 〇〇 基本給 123456
  2. 20日ごろ「試算」が届きます（人数・総支給・差引・0円の人・要確認）。 よければ 【給与確定 2026-09】 と返信します。
  3. 返信すると、明細の確定（スタッフのマイページに出ます）と振込ファイルの作成まで進みます。
  4. みずほビジネスWEBで取り込み → 承認。1回20件・500万円以内に分けたファイルが出ます。 締切は振込日の前営業日17:30です。当日の朝と昼にお知らせします。
  5. 終わったら 【振込承認済み 2026-09】 と返信します。

昇給（毎年4月）

2か月前（2月ごろ）に「今年の昇給を決めましょう」とお知らせが届きます。終わるまで週1回くり返します。

  • 決めた額を入れる … node raise.js plan 2027-04-01 〇〇〇〇 000000（氏名と新しい額）
  • 今回は上げない人も残す … node raise.js skip 2027-04-01 〇〇〇〇（「決めた」と「忘れた」を区別するため）
  • 給与へ反映 … node raise.js apply 2027-04-01
昇給の3か月後に「社会保険の月額変更（随時改定）の確認」が自動で届きます。 2等級以上動く人がいると届出が要ります。2026年は4月昇給→7月から6名の等級が変わりました（人数だけ・氏名は画面で確認します）。

賞与（7月・12月）

支給日の45日前から順にお知らせが届きます（回を決める→誰にいくら→明細→確定→振込）。

  • 回を作る … node bonus.js plan 2026-12 2026-12-04 冬
  • 対象者を見る … node bonus.js check 2026-12（在籍・入社からの期間・算定期間の欠勤を出します）
  • 各人を決める … node bonus.js set 2026-12 〇〇〇〇 2（基本給の2か月分）／… 円 〇〇〇〇〇〇（金額で）
  • 明細 … node bonus.js build 2026-12 --save → 確定 node bonus.js confirm 2026-12
就業規則と実際の支給日がずれています。規則は「7月・12月の最初の金曜日」ですが、 2026年7月の実際の支給は7月10日（第2金曜）でした。賞与は「支給日に在籍している人に払う」決まりなので、 どちらかに揃えてください。

困ったとき

  • 金額が違う気がする … 画面のExcel出力と、会計士の支給控除一覧表を並べて見ます。1円単位で合う作りです。
  • スタッフから「明細が見えない」 … その月が確定済みか確認します。確定していない月は出ません。
  • パスコードを忘れた … serverpc の設定に入っています。院長がクリップボードで確認してください。
  • いま何をすればいいか分からない … node pay_calendar.js --text で予定が出ます。
